# Caso de éxito

Solo con datos reales que dé el usuario. Si falta algo, preguntalo; nunca lo completes con supuestos.

1. Pedí: cliente (o si va anónimo, por ejemplo "PYME alimenticia de Mar del Plata"), permiso del cliente para publicar, situación inicial, qué hicimos, cuánto duró, resultados **medidos** (con cómo se midieron) y, si hay, una frase textual del cliente.
2. Escribí el caso con esta estructura:
   - Título con el resultado principal.
   - `[ SECTOR ]` · `[ SOLUCIÓN ]` · `[ DURACIÓN ]` en etiquetas mono.
   - El problema (2 a 3 frases), la solución (3 a 4 frases), los resultados (lista con números medidos), la cita del cliente.
   - Llamado a la acción al diagnóstico sin cargo.
3. Entregá también una versión corta para LinkedIn (aprox. 150 palabras).
4. Pasalo por `/revisar-texto`.
5. Si los datos reales reemplazan las métricas de referencia de la web, proponé el cambio en `content.js` (métricas e `impactNote`) y mostralo con `/vista-previa` antes de publicar.
